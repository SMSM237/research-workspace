# 연구 위젯 0.3.3

기존 Obsidian의 `Tasks/할 일.md`를 읽고 수정하는 개인 설치용 Android 위젯입니다. 할 일 데이터를 새 형식으로 옮기지 않습니다.

## 휴대전화에서 설정
1. `Research-Widget-0.3.3.apk`를 설치합니다. 이전 ‘논문 분석’ 앱과 같은 패키지이므로 업데이트할 수 있습니다.
2. **연구 위젯 → Vault 폴더 연결**에서 `.obsidian`, `Tasks`, `Dashboard`가 들어 있는 Vault 최상위 폴더를 선택하고 접근을 허용합니다. `Dashboard`나 `Tasks` 폴더 자체를 선택하지 마세요.
3. Obsidian Vault 이름과 `Tasks/할 일.md` 경로를 확인합니다. **설정 저장 · 연결 확인**에 오늘 항목 수가 표시되어야 합니다.
4. 동기화 연결을 선택합니다. 자동 선택은 GitSync 앱이 있으면 사용하고, 없으면 Obsidian Git으로 연결합니다. GitSync 저장소가 여러 개면 화면에 표시된 순서대로 1부터 번호를 지정하세요. 비우면 GitSync의 현재 저장소를 사용합니다.
5. **홈 화면에 위젯 추가**를 누릅니다. 기본은 4×2이며, 길게 눌러 크기를 바꿀 수 있습니다. 예전 위젯이 작게 남아 있으면 다시 배치하거나 크기를 늘리세요.

## 0.3.3 변경
- 회의 탭의 추가 버튼은 회의 제목·날짜·시간 입력창을 엽니다. `Meetings/Schedule`에 대시보드와 동일한 회의 일정으로 저장합니다.
- 할 일 탭의 추가·수정은 기존 `Tasks/할 일.md`를 사용합니다. 회의를 추가해도 할 일 파일은 바뀌지 않습니다.
- 입력 중 화면이 다시 만들어져도 입력 종류·제목·날짜·시간을 유지합니다. 저장 버튼 연타와 같은 저장 요청의 재시도를 중복 회의로 만들지 않습니다.
- **Git 동기화만으로 앱은 업데이트되지 않습니다. 0.3.3 APK를 기존 앱 위에 설치하세요.** 위젯과 Vault 연결은 유지됩니다.
- 이전 버전에서 할 일로 잘못 저장된 항목은 자동 변환하지 않습니다. 의도한 회의 제목·날짜·시간을 확인해 회의로 다시 입력하세요.

## 0.3.2 변경
- 물결은 가로로 채워지는 앞쪽 경계에서 움직입니다. 내부 수면 무늬를 없애고 이전 비율에서 새 비율까지 바뀐 구간만 채우거나 비웁니다.
- 동기화 아이콘은 양쪽 꼭지 방향이 명확한 두 화살표로 다시 그렸습니다. 아이콘과 글자는 같은 색입니다.
- 타원 나선 대신 아이콘·글자가 각자 있던 자리에서 중앙으로 차례로 모입니다. 체크와 주변 빛 효과는 유지합니다.
- 매 요청 단계마다 새 네이티브 재생 객체를 만들고, 모션 중 전체 위젯 새로고침이 재생을 초기화하지 않도록 했습니다. 약 4초 피드백이 끝나면 목록·연결 상태를 갱신합니다.
- Android 12 이상은 진행 경계 애니메이션을 사용하고, 이전 버전과 모션 감소 설정에서는 정적 비율을 표시합니다. 실제 휴대전화의 프레임 속도는 런처에 따라 다릅니다.

## 0.3.1 변경
- 동기화 화살표의 방향과 색을 맞췄습니다. 아이콘과 글자가 각각 나선으로 모입니다. 마지막 체크와 빛 효과의 그리기 코드는 유지했습니다.
- 모션 프레임을 20ms 간격으로 구성하고, 매 프레임을 위젯에 전송하던 방식을 제거했습니다. Android 9 이상은 네이티브 AnimatedImageDrawable, 이전 버전은 프레임 drawable을 사용합니다. 요청 단계 변경 때만 위젯을 갱신합니다.
- 물결 바를 할 일/회의 탭과 완료 수 사이에 배치했습니다. Android 12 이상에서는 완료 수가 바뀔 때 약 2초 동안 물결이 재생됩니다. 구형 Android에서는 완료 비율을 정적으로 표시합니다.
- 목록 위·아래 간격을 8dp로 맞췄습니다. 바깥 모서리 20dp와 안쪽 여백 8dp에 맞춰 아래 버튼은 12dp, 탭은 바깥 12dp/안쪽 10dp로 정리했습니다.
- 할 일 추가·수정창의 기본 버튼 elevation/눌림 그림자를 제거해 그림자가 사각 영역에 잘리는 문제를 수정했습니다. 눌림 색 효과는 유지합니다.

## 0.3.0 변경
- 기본 4×2. 3×2부터 크게 늘릴 수 있고, 높이와 방향에 맞춰 목록 밀도가 바뀝니다. 실제 칸 크기는 홈 런처에 따라 다릅니다.
- 할 일 / 회의 탭으로 전환합니다. 완료 수와 물결 진행 바는 현재 탭을 따릅니다. 오늘 이후의 회의 일정이 표시됩니다.
- 체크는 화면을 띄우지 않고 저장합니다. 회의 완료 상태도 원래 일정 노트에 저장됩니다.
- 추가·수정은 기존의 작은 웜그레이 카드에서 입력합니다. 삭제는 두 번 확인합니다.
- 아래 네 버튼은 추가 / 현재 탭 노트 열기 / 분석 요청 / 동기화입니다. 추가는 오늘 할 일을 작성합니다.
- 동기화·분석 버튼은 글자가 모인 뒤 체크와 짧은 빛 효과를 보이고 2초 뒤 돌아옵니다. **체크는 요청 전달 확인이며, Git 업로드나 분석 완료를 뜻하지 않습니다.** 시스템 모션 감소를 켜면 회전 효과를 생략합니다.
- Git 점은 읽을 수 있는 `.git/FETCH_HEAD`가 최근 15분 이내 갱신되고 요청 이후의 기록일 때만 초록색입니다. 노란색은 요청 중, 빨간색은 전달 오류, 회색은 미확인입니다. 점을 누르면 상세 설명을 확인합니다. GitSync가 이 파일이나 수정 시각을 제공하지 않으면 실제 동기화가 됐더라도 회색일 수 있습니다.
- Git 점은 새로 읽을 때 갱신되며 상시 서버 접속을 보장하지 않습니다. 연결 진단용 분석 결과를 Git 성공 증거로 사용하지 않습니다.

앱을 삭제하지 말고 새 APK를 열어 업데이트하세요. Vault 연결은 유지됩니다. 오래된 위젯이 그대로면 위쪽 완료 수를 눌러 새로 읽거나 위젯 크기를 한 번 바꾸세요.

## 사용
- 체크 아이콘: 완료/미완료 전환. 완료 날짜도 노트에 기록합니다.
- 할 일 이름: 내용 수정. 편집 창의 삭제 버튼으로 해당 항목만 지웁니다.
- 추가: 오늘 할 일을 한 줄로 작성합니다.
- 오른쪽 완료 수: 파일을 다시 읽습니다. 목록 안에서 위아래로 스크롤합니다.
- 회의: Obsidian의 회의 일정 노트를 엽니다. 위젯 높이를 충분히 늘리면 다음 회의도 표시됩니다.
- 분석: PC Inbox에 있는 미완료 논문을 최대 10편 처리하도록 요청 파일을 저장하고 동기화를 요청합니다. 남아 있는 요청은 재사용합니다.
- 동기화: 설정한 GitSync 또는 Obsidian Git에 동기화를 요청합니다. `동기화 요청`은 전송 성공을 뜻하지 않습니다. 동기화 앱에서 완료 여부를 확인하세요.
- 아래 분석 상태: Git으로 받은 PC 처리 상태입니다. 실시간 연결 표시가 아니며, 마지막 동기화 시점의 정보입니다.

완료한 항목은 오늘까지 회색 취소선으로 보이고 다음 날 목록에서 숨겨집니다. 과거 기록은 파일에 남습니다. 미완료는 다음 날에도 보이고, 미래에 예정한 일은 해당 날짜부터 표시됩니다. 위젯에서 기록한 완료 날짜는 Git 동기화 후 기존 주간 기록에 반영됩니다.

## 연결 조건과 한계
- Obsidian Git 방식은 Vault에 Figure First Reader 0.7.1 및 Git 플러그인이 활성화되어 있어야 합니다. 동기화가 끝날 때까지 Obsidian을 잠시 열어 두세요.
- PC 분석 요청에는 Windows PC의 Obsidian·Codex와 로컬 수신 설정이 필요합니다. 이전 연결 검증에서 진단 요청 전달을 확인한 경로입니다. 이번 UI 업데이트에서는 실제 분석을 시작하지 않았습니다. 유휴 상태 자동 시작과 실제 휴대전화에서 전체 논문 분석 완료까지 이어지는 검증은 별도입니다.
- 현재 `Inbox/`는 Git에서 제외되어 있습니다. 휴대전화 Inbox에 PDF를 넣는 것만으로 PC에 전송되지 않습니다. 분석할 PDF는 PC Inbox에 준비하세요.
- GitSync는 동기화 완료 콜백을 제공하지 않으므로 위젯에서 성공을 추측하지 않습니다. 위젯은 별도 로그인이나 Git 비밀번호를 저장하지 않습니다.
- 외부 변경은 새로고침, 앱 재열기, 동기화 요청 뒤 재확인 및 Android의 주기 갱신으로 반영합니다. Android의 절전 상태에 따라 자동 갱신은 늦어질 수 있습니다.
- 같은 항목이 편집 중 바뀌면 저장을 거절합니다. 저장 직전 원문을 재확인하고 최근 20개 수정 전 사본을 앱 내부에 보관합니다. Android 파일 권한 API는 다른 앱과 공유하는 완전한 잠금을 제공하지 않으므로 Git 전송 중에는 같은 노트의 동시 편집을 피하세요.

## 검증 범위
Android 16 에뮬레이터에서 실제 폴더 선택, 체크·수정·추가·삭제, 파일 재읽기, 앱 재시작, 충돌 보호, 위젯 스크롤 및 크기 변경을 검사했습니다. URI 전달은 테스트용 수신기로 검사했습니다. 실제 휴대전화의 런처·GitSync 계정 연결은 설치 후 확인이 필요합니다. 실제 사용자 할 일은 테스트 데이터로 수정하지 않았습니다.

## 소스 빌드
Java 17, Gradle 8.14.3, Android SDK 35, Android Gradle Plugin 8.11.1을 사용합니다. `local.properties`에 자신의 `sdk.dir`를 지정한 뒤 `gradle :app:assembleDebug`로 빌드합니다. 현재 배포 APK는 개인 설치용 서명된 debug 빌드입니다. 서명 키는 ZIP에 포함하지 않습니다.

`uri-fixture`는 QA 전용 수신기입니다. 휴대전화에 설치할 앱은 `app` 하나뿐입니다. 테스트 소스는 `tests/TaskDocumentTest.java`에 있습니다. 저장소 비밀키, 사용자 노트, 계정 정보는 소스 ZIP에 포함하지 않습니다.

GitSync 연결 규격: https://gitsync.viscouspotenti.al/wiki/sync-options/background/custom-intent
